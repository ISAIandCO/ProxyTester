## Что это

**ProxyTester** проверяет серверы из ваших подписок **VLESS и Hysteria2** и помогает выбрать подходящий для NotebookLM, Gemini или другого сайта.

У одного сервера может быть хорошая скорость, но не работать нужный сервис. Другой может открывать сервис только через Cloudflare WARP. Программа проверяет оба варианта и собирает результаты в понятный HTML-отчёт.

Подписку предоставляет ваш VPN-провайдер. Если для её получения нужен **HWID**, его можно указать при добавлении подписки.

## Возможности

- Загрузка одной или нескольких подписок по ссылке и импорт локальных файлов.
- Проверка задержки, скорости загрузки и, при необходимости, отдачи.
- Проверка NotebookLM, Gemini и ваших сайтов в браузере.
- Сравнение **VPN** и **VPN → WARP** для каждого сервера.
- Автоматическое создание WARP-конфигурации через проверяемый VPN.
- Вход в аккаунт через выбранный сервер с сохранением сессии.
- Автоматический поиск **Chrome, Edge и Brave**, выбор браузера при наличии нескольких.
- Отчёт с поиском, фильтрами, сортировкой и экспортом CSV/JSON.
- Остановка, продолжение незавершённой проверки и повтор ошибок.

## Установка

### [Скачать последнюю версию](https://github.com/ISAIandCO/ProxyTester/releases/latest)

1. Скачайте **ProxyTester-windows-x64.zip** из раздела **Assets**.
2. Распакуйте архив целиком в отдельную папку с правом записи.
3. Запустите **ProxyTester.exe** или **Start.cmd**.

Поддерживаются **Windows 10 и 11, 64 бита**. В архив уже включены необходимые компоненты и Chromium. Устанавливать Python и запускать программу от администратора не требуется.

## Первая проверка

1. На вкладке **Подписки** нажмите **Добавить…**, вставьте ссылку и при необходимости HWID. Вместо ссылки можно добавить локальный файл.
2. На вкладке **Сервисы** оставьте NotebookLM/Gemini или добавьте нужные сайты.
3. На вкладке **Параметры** выберите, нужны ли скорость и проверка **VPN → WARP**.
4. На вкладке **Запуск** нажмите **Запустить**.
5. После завершения откройте отчёт кнопкой **Открыть отчёт**. По умолчанию он открывается автоматически.

Настройки сохраняются в **config.json**. Их можно открыть или сохранить в другой файл кнопками в верхней части окна.

### Какие параметры выбрать

| Задача | Рекомендация |
| --- | --- |
| Сравнить скорость серверов | Параллельных серверов: **1** |
| Быстрее проверить доступность сайтов | Отключить измерение скорости; параллельных серверов: **2–4** |
| Проверить только обычный VPN | Отключить **Проверять VPN → WARP** |
| Проверить несколько серверов | Загрузить серверы, выделить строки и выбрать режим **Выбранные серверы** |
| Проверить медленные сайты | Увеличить сетевой таймаут и бюджет на сервер |

По умолчанию измерение скорости скачивает около **5 MB на маршрут**. Для 90 серверов с включённым WARP это примерно **900 MB**, дополнительно загружаются страницы сайтов. Объём можно уменьшить или отключить измерение скорости.

## Вход в NotebookLM, Gemini и другие сервисы

Если сервис требует аккаунт, сначала сохраните сессию:

1. На вкладке **Запуск** нажмите **Загрузить серверы** и выделите один сервер.
2. Нажмите **Войти через выбранный сервер…**.
3. Если найдено несколько браузеров, выберите **Chrome, Edge или Brave**. Выбор сохранится.
4. В открывшемся браузере войдите в сервис, при необходимости подтвердите вход и пройдите CAPTCHA вручную.
5. Вернитесь в ProxyTester и нажмите **Сохранить сессию**.
6. Запустите проверку серверов.

Для входа открывается отдельный временный профиль браузера. В нём нужно войти заново. Приложение проверяет, что браузер использует выбранный VPN.

Чтобы сменить браузер, откройте **Параметры → Свой Brave / Chrome / Edge → Найти…**. Если браузер установлен в нестандартном месте, укажите его файл кнопкой **Обзор…**. Если подходящий браузер не установлен, используется встроенный Chromium. Firefox для этого способа входа не поддерживается.

Если Google сообщает «Возможно, этот браузер или приложение небезопасны», попробуйте другой найденный браузер и другой VPN-сервер. Решение о входе принимает Google; сама загрузка страницы ещё не подтверждает успешную авторизацию.

## Как читать отчёт

Для каждого сервиса показаны результаты обычного VPN и маршрута через WARP. Можно отфильтровать страну, протокол, доступность и признаки защиты, отсортировать серверы по задержке или скорости.

| Результат | Что означает |
| --- | --- |
| **Доступен** | Найден заданный признак готовности интерфейса сервиса |
| **Не подтверждено** | Страница открылась, но готовность сервиса не подтверждена; может требоваться вход |
| **Региональное ограничение** | Сервис сообщил о неподдерживаемой стране |
| **Защита / блок** | Обнаружена проверка, CAPTCHA или блокировка |
| **Ошибка сети** | Страница не загрузилась по проверяемому маршруту |
| **Ошибка проверки CSS/regex** | Нужно исправить условие проверки сервиса в настройках |

**Страница входа и HTTP 200 не считаются доказательством доступности.** Для NotebookLM проверяется наличие кнопки создания блокнота, для Gemini — поля запроса. Программа не создаёт блокноты и не отправляет запросы от вашего имени.

Метка **«Только WARP»** показывает серверы, на которых сервис подтвердился через WARP, а для обычного VPN зафиксирована ошибка или блокировка. Если результат обычного VPN неизвестен, он не считается неработающим.

Наведите указатель на статус, чтобы увидеть причину, или нажмите название сервера для подробностей. Кнопки **CSV** и **JSON** выгружают отфильтрованные строки. Полный отчёт также сохраняется рядом с HTML.

## Остановка и повторная проверка

Кнопка **Остановить** завершает текущую работу с сохранением промежуточного результата.

В списке режимов на вкладке **Запуск** доступны:

- **Продолжить прерванный запуск** — проверить оставшиеся серверы.
- **Повторить ошибки** — повторить проверки с техническими ошибками.
- **Выбранные серверы** — проверить только выделенные строки, в том числе серверы с региональной блокировкой.

Если меняете условия проверки, начинайте новый запуск в режиме **Все серверы**.

## Обновление

Закройте приложение, распакуйте новую версию в отдельную папку и перенесите **config.json**. Для сохранения истории и WARP-кэша можно перенести папки **data** и **reports**. При необходимости перенесите файл сессии и выберите его заново в параметрах. Проверьте пути к локальным подпискам и браузеру.

## Что важно знать

- WARP работает поверх выбранного VPN. Если сервер не пропускает нужный трафик, каскад может не подключиться.
- Результаты относятся к моменту проверки. Доступность может зависеть от IP, страны и аккаунта.
- CAPTCHA проходят вручную. Программа не обещает обход всех ограничений сервисов.
- Ссылки подписок, HWID, пароли и сессии не включаются в отчёт. Внешние IP и названия серверов в нём остаются.
- **config.json**, файлы сессий и **data/warp** содержат секретные данные. Не прикладывайте их к публичным сообщениям об ошибке.
