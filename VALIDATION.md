# Проверка версии 1.1.0 — GUI

Дата: 15 ноября 2026 года. Проверенный код:
[`7bd0abe`](https://github.com/ISAIandCO/ProxyTester/commit/7bd0abe58dd4a70e74b050c41911d58625a5b3d3).

* [Успешный Windows workflow](https://github.com/ISAIandCO/ProxyTester/actions/runs/43743815481)
* [Готовая Windows x64 сборка с GUI](https://github.com/ISAIandCO/ProxyTester/actions/runs/43743815481/artifacts/14172959971)

В версии 1.1.0 добавлено нативное окно настройки и запуска:
подписки/HWID и локальные файлы, редактор сервисов и признаков готовности,
параметры измерений, загрузка/выбор серверов, повтор ошибок и продолжение,
прогресс и подробности ошибок, штатная остановка, авторизация через выбранный
VPN и сохранение сессии, открытие отчёта.

Сборка содержит `ProxyTester.exe` (окно без консоли) и `ProxyTesterCLI.exe`
(прежние консольные команды). Оба используют один тестовый механизм.
Существующий config.json читается без конвертации; настройки окна сохраняются
отдельно и не меняют подпись измерительных параметров для --resume.

К прежним 61 проверке добавлены 10 GUI-проверок:

* сохранение и загрузка настроек, объёмов в MB, HWID и дополнительных полей;
* редактирование подписок и сервисов в настоящих Tk-диалогах;
* отказ от записи некорректных настроек;
* загрузка серверов, запуск существующего Runner и сохранение отчёта из окна;
* передача выбранных ID, отмена задачи с ожиданием cleanup, подтверждение
  авторизации через очередь GUI и asyncio.Event;
* получение результата и обработка ошибок рабочего потока без вывода секретного URL;
* отображение четырёх вкладок и видимость строки состояния на Windows.

В GUI-тесте запуска использованы невалидные записи подписки: проверен путь
окно → Runner → сохранение отчёта. Остановка и подтверждение авторизации
проверены контрольными async-задачами без настоящего аккаунта. Реальные VPN,
WireGuard и Chromium проверяются прежним отдельным интеграционным набором.
Границы проверки коммерческих серверов, публичного WARP и Google-аккаунта
описаны ниже.

## Результат

**71 тест прошёл без пропусков:** 40 модульных, 20 интеграционных,
1 браузерный для HTML-отчёта, 10 GUI-проверок. Windows Server 2025 x64,
Python 3.12.10, Xray 26.11.9, sing-box 1.14.4 и Playwright 1.62.0.

Реальные локальные соединения проверены для VLESS TCP, XHTTP, REALITY,
XHTTP+REALITY, Hysteria2+Salamander+TLS и WireGuard поверх VLESS/XHTTP/Hysteria2.
Проверены download/upload, отсутствие прямого fallback после остановки VPN,
регистрация через VPN, генерация рабочего ключа WireGuard, HWID header/query/bearer,
429, кэш, параллельная изоляция и отмена/возобновление.

PyInstaller собрал два exe с общей папкой runtime. Готовый `ProxyTesterCLI.exe`
прошёл проверку версии, готовый `ProxyTester.exe` запущен в smoke-режиме:
окно с формами создано и штатно закрыто. Четыре вкладки осмотрены по снимкам
Windows; строка состояния доступна и на небольшом рабочем столе runner.

## Границы проверки

* Локальный регистрационный API — фикстура ответов Cloudflare. Шифрование,
  ключи, VPN-транспорт и передача данных настоящие. Это не публичный WARP.
* Действующая коммерческая подписка/HWID и Google-аккаунт не предоставлены.
  Принятие HWID поставщиком, публичная регистрация WARP через его серверы
  и NotebookLM/Gemini с аккаунтом пользователя остаются непроверенными.
* Положительный статус сервиса означает прохождение заданной проверки
  готовности интерфейса. Создание блокнотов, отправка запросов и платные
  операции автоматически не выполняются.
* Локальные скорости проверяют измеритель, а не качество коммерческих VPN.
* CI выполнялся на Windows Server 2025. Отдельного запуска на физических
  Windows 10/11 в этой работе не было.
* Проверено штатное прерывание. Принудительное завершение через Task Manager
  или отключение питания не проверялись.

В исходной Linux-среде прошли 40 модульных тестов и 3 теста worker GUI.
Нативные Tk-тесты выполнялись на Windows, поскольку в Linux-среде нет display.
