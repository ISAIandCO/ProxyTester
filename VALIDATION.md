## Границы проверки

* Локальный регистрационный API имитирует только ответы Cloudflare, но
  последующее WireGuard-шифрование, ключи, VPN-транспорт и передача данных
  настоящие. Эти фикстуры не выдаются за измерения публичного WARP.
* Действующая коммерческая подписка/HWID не предоставлены. Конкретные серверы,
  принятие HWID поставщиком и публичная регистрация Cloudflare через них
  не проверены.
* Авторизованный аккаунт Google не предоставлен. Доступность NotebookLM/Gemini
  с аккаунтом пользователя не проверена. Положительный статус означает
  выполнение заданной проверки готовности интерфейса; создание блокнота,
  отправка запроса и платные операции автоматически не выполняются.
* Локальные скорости нужны для проверки измерителя. Это не замеры скорости
  коммерческих VPN и не основание для сравнения провайдеров.
* CI выполнялся на Windows Server 2025. Отдельного интерактивного запуска на
  физических Windows 10/11 в этой работе не было.
* Принудительное завершение через Task Manager/отключение питания не равно
  штатному Ctrl+C. Очистка процессов и запись checkpoint проверены для
  штатного прерывания.

В исходной Linux-среде выполнены 40 модульных проверок и отдельная реальная
передача через Xray TCP/XHTTP/REALITY/XHTTP+REALITY. Полный sing-box/Chromium
прогон там блокируется ограничениями socket/netlink, поэтому полный результат
выше получен именно на Windows runner.
